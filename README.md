# 띠링 (내 띠가 알려 주는 오늘의 운세 PWA)

> 띠링! 오늘 내 띠의 운세가 도착했어요

생년월일(양력/음력·윤달)과 태어난 시를 넣고 도장을 누르면, 사주팔자 여덟 글자가 로또 추첨기처럼 돌다가 하나씩 멈추고 오늘의 운세가 나옵니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (같은 와이파이의 휴대폰에서도 접속 가능)
npm run build    # dist 폴더 생성 → 그대로 배포
npm run preview  # 빌드 결과 확인
```

서비스 워커는 빌드된 배포본(HTTPS)에서만 등록됩니다. 배포 후 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 설치됩니다. 업데이트를 배포할 때는 `public/sw.js`의 `VERSION` 값을 올려 주세요.

## 화면 구성

- **사주 등록**: 시작 화면 → 이름·성별 → 생년월일(양력/음력/윤달) → 태어난 시간(모름 가능) → 고민 최대 3개 → 확인 → 여덟 글자 추첨 → 일주 성향 소개
- **홈**: 띠 캐릭터 인사, 날짜 이동, 하루 한 번 운세 뽑기(일진·당사주·주역·총운 네 칸 추첨), 총운·고민 맞춤 운세·분야별 운(누르면 이유와 실천 팁)·행운·괘·피할 것
- **만세력**: 일주 성향, 천간·지지·십성·지장간·12운성·12신살·공망, 오행 분포, 대운 흐름. 밑줄 친 용어를 누르면 풀이가 올라와요
- **달력**: 날마다 표정이 바뀌는 띠 캐릭터와 점수, 특별한 날 아이콘(재물 기회·인연·귀인·충돌·오해)
- **설정**: 내 정보 수정, 소리·진동·큰 글씨, 용어 사전, 계산 방법, 정보 초기화

## 폴더 구조

```

  lib/fortune.js     문장 엔진 (해요체, 바넘 효과, 분야별 이유·팁, 고민 맞춤, 특별한 날)
```

## 계산 방식 (정확도)

**여덟 글자**
- 연주·월주: VSOP87 태양 황경으로 구한 실제 절입 시각 기준 (입춘 등 발표 시각과 1~2분 이내)
- 시주: 태어난 도시 경도로 진태양시 보정 + 1954~1961년 표준시(UTC+8:30), 1987~1988년 서머타임 반영
- 자시: 기본은 23시부터 다음 날 일주, 설정에서 야자시 선택 가능
- 대운수: 출생 순간부터 앞/뒤 절입 시각까지의 실제 날수 ÷ 3

**하루 점수 (무작위 요소 없음)**
| 항목 | 비중 | 내용 |
|---|---|---|
| 명리 | 70% | 원국 세력(월지 가중)으로 신강·신약 → 용신·희신·기신(+조후). 그날 일진(천간·지지), 월운·세운이 용신인지 기신인지, 원국 네 지지와 합·충·형·원진·해, 일간과 천간합, 12운성, 공망 |
| 당사주 | 15% | 생년·생월 별 + 오늘 일진으로 오늘의 별 |
| 주역 | 15% | 매화역수: 생년월일 숫자로 본괘, 오늘 날짜로 동효 → 변괘 |

분야별 점수는 그날 들어온 십성(재성=금전, 관성=커리어, 남성은 재성·여성은 관성=연애, 인성·비겁=건강)이 나에게 용신인지 기신인지로 가감합니다. 홈 화면 "오늘 운세의 근거"에 어떤 요소가 점수를 올리고 내렸는지 그대로 보여 줍니다.

문구를 바꾸고 싶으면 `src/lib/fortune.js`의 문장 목록만 고치면 됩니다.
