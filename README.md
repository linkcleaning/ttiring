# 띠링 (내 띠가 알려 주는 오늘의 운세 PWA)

> 띠링! 오늘 내 띠의 운세가 도착했어요

생년월일(양력/음력·윤달)과 태어난 시를 넣고 도장을 누르면, 사주팔자 여덟 글자가 로또 추첨기처럼 돌다가 하나씩 멈추고 오늘의 운세가 나옵니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (같은 와이파이의 휴대폰에서도 접속 가능)
npm run build    # dist 폴더 생성 → 그대로 배포
npm run preview  # 빌드 결과 확인
```

앱 아이콘은 부적 느낌 바탕에 한자 占(점칠 점)과 붉은 福 낙관을 넣은 그림이며, 글꼴에 기대지 않도록 32·144·192·256·384·512px PNG와 apple-touch-icon(180px), 마스커블 아이콘을 모두 PNG로 넣어 두었습니다.

서비스 워커는 빌드된 배포본(HTTPS)에서만 등록됩니다. 배포 후 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 설치됩니다. 업데이트를 배포할 때는 `public/sw.js`의 `VERSION` 값을 올려 주세요.

## 화면 구성

- **사주 등록**: 시작 화면 → 이름·성별 → 생년월일(양력/음력/윤달) → 태어난 시간(모름 가능) → 고민 최대 3개(사랑·돈·일·삶 4개 묶음, 25가지) → 확인 → 여덟 글자 추첨 → 성격 풀이(한 줄 요약, 자주 듣는 말, 연애·일·스트레스·에너지 타입, 가장 강한 힘, 특별한 별, 잘 맞는 띠)
- **홈**: 띠 캐릭터 인사, 날짜 이동, 하루 한 번 운세 뽑기(일진·당사주·주역·총운 네 칸 추첨), 총운 한마디, **오늘의 운세 풀이(3문단·500~700자, 날마다 다른 글)**, 고민 맞춤 운세·분야별 운(누르면 이유와 실천 팁)·행운·괘·피할 것
- **만세력**: 일주 성향과 한 줄 요약, "이런 말 자주 듣죠?", 연애·일·스트레스·에너지 타입, 십성 분포로 보는 타고난 힘, 잘 맞는 띠와 조심할 띠, 내 사주의 특별한 별(신살), 만세력 표(천간·지지·십성·지장간·12운성·12신살·공망), 신강약·용신, 오행 분포, 대운 흐름. 밑줄 친 용어를 누르면 풀이가 올라와요
- **달력**: 날마다 표정이 바뀌는 띠 캐릭터와 점수, 특별한 날 아이콘(재물 기회·인연·귀인·충돌·오해)
- **여러 사람**: 처음 등록한 사람이 "나"(대표)이고, 가족·연인·친구·직장 동료를 얼마든지 추가할 수 있어요. 홈 맨 위 캐릭터 줄에서 눌러 바로 전환하고, 운세 뽑기는 사람마다 하루 한 번이에요.
- **설정**: 사람 목록 관리(추가·수정·삭제), 내 정보 수정, **매일 아침 알림(시각 지정)**, 소리·진동·큰 글씨, 용어 사전, 계산 방법, 정보 초기화
- **운세 카드 저장·공유**: 홈 결과 아래 "이미지로 저장"을 누르면 1080×1440 PNG 카드를 만들어 저장하거나(공유 지원 기기는) 바로 공유해요. 캔버스로 그리므로 서버가 필요 없어요.
- **아이콘 길게 누르기**: 홈 화면 아이콘을 길게 누르면 오늘의 운세·달력·만세력으로 바로 가는 바로가기가 나와요 (manifest shortcuts).

## 계산 방식 (정확도)

**여덟 글자**
- 연주·월주: VSOP87 태양 황경으로 구한 실제 절입 시각 기준 (입춘 등 발표 시각과 1~2분 이내)
- 시주: 태어난 곳 경도로 진태양시 보정 + 1954~1961년 표준시(UTC+8:30), 1987~1988년 서머타임 반영
- 태어난 곳: 전국 시·군 161곳을 검색해서 고르고(읍·면·동은 속한 시·군 선택), 목록에 없는 곳은 이름과 경도를 직접 넣을 수 있어요 (`src/lib/astro.js`의 `CITY_GROUPS`)
- 자시: 기본은 23시부터 다음 날 일주, 설정에서 야자시 선택 가능
- 대운수: 출생 순간부터 앞/뒤 절입 시각까지의 실제 날수 ÷ 3

**하루 점수 (무작위 요소 없음)**
| 항목 | 비중 | 내용 |
|---|---|---|
| 명리 | 70% | 원국 세력(월지 가중)으로 신강·신약 → 용신·희신·기신(+조후). 그날 일진(천간·지지), 월운·세운이 용신인지 기신인지, 원국 네 지지와 합·충·형·원진·해, 일간과 천간합, 12운성, 공망 |
| 당사주 | 15% | 생년·생월 별 + 오늘 일진으로 오늘의 별 |
| 주역 | 15% | 매화역수: 생년월일 숫자로 본괘, 오늘 날짜로 동효 → 변괘 |

분야별 점수는 그날 들어온 십성(재성=금전, 관성=커리어, 남성은 재성·여성은 관성=연애, 인성·비겁=건강)이 나에게 용신인지 기신인지로 가감합니다. 홈 화면 "오늘 운세의 근거"에 어떤 요소가 점수를 올리고 내렸는지 그대로 보여 줍니다.

홈 화면의 "오늘의 운세 풀이"는 그날의 등급·십성·오행 용신/기신·12운성·합충·당사주 별·주역 괘·요일을 조립해서 만들기 때문에, 생년월일이 같아도 날마다 다른 글이 나옵니다 (1년치 1,825건을 돌려 모두 다른 글임을 확인). 문구를 바꾸고 싶으면 `src/lib/fortune.js`의 `DAY_OPEN`·`GOD_LONG`·`STAGE_LONG`·`REL_LONG`·`DAY_CLOSE` 목록만 고치면 됩니다.

## 알림이 울리는 방식

PWA는 앱이 꺼진 상태에서 정확한 시각에 알림을 울리기 어렵습니다. 띠링은 두 가지를 함께 씁니다.

1. **주기적 백그라운드 동기화**: 안드로이드에서 홈 화면에 설치한 경우, 브라우저가 하루에 한두 번 서비스 워커를 깨우고 그때 설정 시각이 지났으면 알림을 띄웁니다. 서비스 워커는 수시로 꺼지므로 알림 시각과 "오늘 보낸 날"을 `ttiring-notify` 캐시에 적어 두고, 깨어날 때 다시 읽습니다(이 캐시는 버전을 올려도 지우지 않습니다).
2. **따라잡기**: 앱을 열거나 화면으로 되돌아올 때, 설정 시각이 지났는데 오늘 알림을 아직 못 봤으면 그 자리에서 띄웁니다.

정확한 시각에 꼭 울려야 한다면 Capacitor로 감싸 네이티브 로컬 알림을 쓰면 됩니다. 그때 `src/lib/notify.js`의 시각 설정을 그대로 가져다 쓰면 됩니다.

## 홈 화면 위젯

iOS와 안드로이드의 진짜 홈 화면 위젯은 웹(PWA)에서 만들 수 없고 네이티브 코드가 필요합니다. 지금은 가장 가까운 대체로 **아이콘 길게 누르기 바로가기**를 넣어 두었습니다. 나중에 위젯을 만들 때 쓸 수 있도록, 오늘 점수·등급·띠 캐릭터 표정은 `computeFortune()` 한 번 호출로 바로 얻을 수 있게 되어 있습니다.
